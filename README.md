# Financial Fraud Detection System

## Project Overview

This project uses Machine Learning techniques to detect fraudulent financial transactions and assist organizations in preventing financial losses.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Plotly

## Features

- Fraud Detection
- Transaction Analysis
- Machine Learning Classification
- Interactive Dashboard
- Financial Risk Monitoring

## Dataset

Synthetic Financial Dataset containing transaction information and fraud labels.

- FRAUD_DETECTION_1.py

- Synthetic_Financial_datasets_log.csv
